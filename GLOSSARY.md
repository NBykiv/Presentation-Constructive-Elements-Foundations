# 📚 Глосарій ключових термінів

## А
**Архітектурно-конструктивні елементи** — основні складові частини будівлі, що виконують несучі або огороджувальні функції

## В
**Вогнестійкість** — здатність матеріалу або конструкції витримувати високі температури при пожежі

**Вимоги до фундаментів** — технічні, конструктивні та експлуатаційні умови, які повинен задовольняти фундамент

## Г
**Ґрунт** — мінеральна або органо-мінеральна товща, що є основою для фундаменту

**Органічні ґрунти** — торф, мул; низька несуча здатність, потребують заміни

**Глинисті ґрунти** — глини, суглинки; змінність властивостей від вологості, морозне пучення

**Піщані ґрунти** — піски різної щільності; залежність властивостей від ущільнення

**Скельні ґрунти** — найміцніші основи; не розмокаються; мінімальне осідання

## К
**Каркас** — система опор та балок, що сприймає навантаження у каркасних схемах

**Капітальність будівлі** — ступінь стійкості та довговічності конструкцій

**Колони** — див. опори

**Конструктивна схема** — система організації несучих конструкцій будівлі

**Конструктивні елементи** — окремі складові частини будівельної конструкції

**Конструкції несучі** — елементи, що передають навантаження до основи

## М
**Модульні розміри** — уніфіковані розміри, кратні основному модулю

## Н
**Надійність** — здатність конструкції виконувати свої функції без руйнування

**Несуча здатність** — максимальне навантаження, яке може витримати основа

**Нормативні документи** — ДБН, ДСТУ та інші стандарти будівництва

## О
**Основа** — верхній шар ґрунту, що сприймає навантаження від фундаменту

**Опори (колони)** — вертикальні конструкції, що передають навантаження від перекриття

**Осідання** — вертикальне переміщення фундаменту в ґрунті

## П
**Перегородки** — тонкі конструкції для розділення внутрішнього простору; не несучі

**Перекриття** — горизонтальні конструкції, що розділяють поверхи

**Перепад** — різниця висот на ділянці будівництва

**Промерзання (глибина)** — глибина проникнення морозу в ґрунт взимку

## Р
**Ростверк** — конструкція пальового фундаменту, що об’єднує оголовки паль і передає на них навантаження

## С
**Пальові фундаменти** — фундаменти, що передають навантаження на ґрунт через палі

**Схема безкаркасна** — стіни виконують несучу функцію, опор немає

**Схема каркасна** — жорсткий каркас (опори + балки) сприймає навантаження

**Схема напівкаркасна** — поєднання елементів безкаркасної та каркасної схем

**Стіни** — вертикальні конструкції, що можуть бути несучими або огороджувальними

**Стовпчасті фундаменти** — окремі опори під кожною колоною; сполучені ростверком

## Т
**Теплозахист** — конструктивні заходи для збереження тепла в будівлі

**Тип ґрунту** — класифікація ґрунту за складом (скельні, піщані, глинисті тощо)

## Х
**Герметичність** — непроникність для вологи та газу

## Ф
**Фундамент** — нижче розташована конструкція, що передає навантаження від будівлі на основу

**Стрічковий фундамент** — безперервна конструкція під несучими стінами

**Фундамент плитний** — суцільна залізобетонна плита під всією будівлею

**Пальовий фундамент** — палі та ростверк; для передавання навантаження на глибші шари ґрунту

## Ц
**Цоколь** — нижня частина зовнішньої стіни, що виступає над планувальною відміткою

## 📊 Класифікація основних елементів

### Конструктивні елементи
- **Несучі:** фундаменти, стіни, опори, перекриття
- **Допоміжні:** перегородки, дахи, сходи
- **Заповнення:** вікна, двері, балкони

### Типи конструктивних схем
1. **Безкаркасні** — стіни несучі
2. **Каркасні** — опори + балки несучі
3. **Напівкаркасні** — комбіновані
4. **Змішані** — різні матеріали

### Типи фундаментів
1. **Стрічкові** — для будівель із несучими стінами
2. **Стовпчасті** — для каркасних будівель
3. **Плитні** — для складних ґрунтів
4. **Пальові** — для слабких ґрунтів або передавання навантаження на глибші шари

### Типи ґрунтів
1. **Скельні** — найкращі
2. **Великоуламкові** — добрі
3. **Піщані** — властивості залежать від щільності
4. **Глинисті** — обмежені
5. **Органічні** — найгірші
