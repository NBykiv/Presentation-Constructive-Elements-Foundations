---

## 🎯 Про презентацію

Ця презентація охоплює важливі аспекти цивільного будівництва:

- **Конструктивні елементи** будівель (фундаменти, стіни, опори, перекриття, дахи, сходи)
- **Конструктивні схеми** (безкаркасні, каркасні, напівкаркасні, змішані)
- **Основи та їх зміцнення** (типи грунтів, способи зміцнення)
- **Класифікація фундаментів** (ленточні, стовпчасті, плитні, свайні)
- **Вимоги до фундаментів** згідно ДБН 2026
